**Subscribe to Texts**

Texts can be a great way to make sure you don’t miss anything. From alerts to action items in our collective advocacy, to reminders before meetings begin, to important updates about an event you’re attending - we’ve got you covered. Each user will have the opportunity to share communication preferences when they register. That said, if you need a chance to opt-in (or opt-back-in), text “JOIN” to (833) 243-1053.

**Member Contributions**

We want to reiterate that every CBO providing restorative programming to people in CA State Prisons is eligible to join the TPW and we are committed to inclusion and community. Membership dues are not a requirement to participate. For organizations that are willing and able, see our [Membership Dues](https://www.thetpw.org/membership-dues) page for more information.
